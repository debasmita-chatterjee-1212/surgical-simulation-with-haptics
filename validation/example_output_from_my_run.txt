HOW TO READ THE RESULTS
  Test 1: solver reproduces the modulus E (error is the end-clamp effect and, for nu = 0.45, volumetric locking of linear tetrahedra).
  Test 2: constant-strain tetrahedra are too stiff in bending on coarse meshes (shear locking); the error falls as the mesh is refined.
  Test 3: tissue response to the proxy load patch approaches the half-space solution as the mesh is refined (a finite 40 mm block adds ~10 % stiffness).
  Test 4: the contact loop is not static at larger depths: the proxy tip does not follow the deepest point of the dimple (contact on/off cycling).
          Use the tissue max displacement column for the tissue response and report the contact loop as a qualitative interaction model.
